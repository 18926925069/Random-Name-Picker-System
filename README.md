# 适用于中文用户

## 随机点名系统

这是一个点名用途的程序，为了极致的兼容性，我们选择基于 .NET Framework 2.0。

## 有什么用

开发给学校用的，可以导入 .txt 格式的名单和手动添加名单，或者您也可以尝试用于其他需要随机抽取的场景。

# Suitable for native English speakers

## Random Roll Call System

This is a program for roll call purposes. For maximum compatibility, we chose to base it on .NET Framework 2.0.

## Why is there this project & What it's for

Developed for schools. And you can import a list from a .txt file or add names manually.
Or, you can also try using it in other scenarios where random selection is needed.
