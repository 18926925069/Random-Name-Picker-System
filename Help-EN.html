Frequently Asked Questions (FAQ)

Q: What is this project used for?
A: It is used for random roll call. For more details, please refer to the Project Readme.md.
Q: I have a ".xlsx" file. How can I convert it into a "txt" file supported by the software?
A: You can use the xlsx-to-txt tool provided in the project for conversion. However, we currently do not support ".xls" (97-03 Worksheet) files.
Q: Why are we using ".NET Framework 2.0"?
A: For ultimate compatibility. In China, companies or schools may refuse to replace their high-performance computers citing "insufficient funds" (even in special economic zones like Zhuhai, there are still quite a few old Win7 machines). This causes many teaching/office computers in most cities to still run on Windows 7 or even Windows Vista. .NET Framework 2.0 (.NET 2.0) can run on most computers running Windows XP and above (unless your system is a third-party slimmed-down version).
Q: Why can't my name list be imported?
A: The program detects the file encoding automatically (UTF-8, UTF-16 and GBK/ANSI files can all be imported directly), so a manual conversion is usually not needed. If the names look garbled after importing, save the file as UTF-8 and import it again.
Q: Are there any formatting requirements for the imported txt file?
A: Yes, but it is very simple: there should be exactly one name per line.
Q: I am worried about my name list data being uploaded or leaked. Will this program leak it?
A: Our application runs entirely locally and never uses any cloud services. As long as your computer is not compromised by malicious attacks, your name list privacy data will not be leaked.
Q: How can I make someone more likely to be picked?
A: Open Settings and use the "Weights" section: select one or more names and press -1 / +1. Weight 1 is the normal chance, weight 2 makes a name twice as likely, and weight 0 means the name cannot be picked in this round. The "Chance" column shows each person's current percentage; the change is saved with OK and discarded with Cancel. You can also put the weight into the name file, for example Alice 3 (a number from 1 to 100 after the name, separated by a space, a tab or a comma); a name without a number gets weight 1.
Q: Why is someone who was just picked not picked again for a while?
A: To avoid calling the same person twice in a row, names picked within the last 30 seconds are left out of the draw. If only these names are left (for example a class of one), the program still picks normally instead of getting stuck.
